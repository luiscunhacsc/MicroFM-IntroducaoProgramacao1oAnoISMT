EXEMPLO RESOLVIDO
Ordenação por seleção
Ordenar.java
void ordenar(int[] v) {
    for (int i = 0; i < v.length - 1; i++) {
        int menor = i;   // procura o menor a partir de i
        for (int j = i + 1; j < v.length; j++) {
            if (v[j] < v[menor]) {
                menor = j;
            }
        }
        trocar(v, i, menor);   // põe-no na posição i
    }
}

EXEMPLO RESOLVIDO
O código da pesquisa binária
int binaria(int[] v, int alvo) {
    int ini = 0;
    int fim = v.length - 1;
    while (ini <= fim) {
        int meio = (ini + fim) / 2;
        if (v[meio] == alvo) { return meio; }
        if (v[meio] < alvo) { ini = meio + 1; }
        else { fim = meio - 1; }
    }
    return -1;
}
⚠️
Condição essencial
Só funciona se o array estiver 
ordenado!
