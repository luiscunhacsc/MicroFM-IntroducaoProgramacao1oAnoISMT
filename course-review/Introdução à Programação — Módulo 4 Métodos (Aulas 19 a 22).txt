=== PAGE 28 ===
A EXPLICAÇÃO
O parâmetro recebe uma cópia
Momento vidas (main) v (perderVida)
Antes da chamada 3 —
Entra em perderVida 3 3 (cópia)
Depois de v-- 3 2
Volta ao main 3 — (desapareceu)
É como dar uma fotocópia: o que escreves na cópia não muda o original.

int lerInteiroEntre(String pergunta, int min, int max) {
    int n;
    do {
        n = Integer.parseInt(IO.readln(pergunta));
        if (n < min || n > max) {
            IO.println("Escolhe entre " + min + " e " + max + ".");
        }
    } while (n < min || n > max);
    return n;
}
