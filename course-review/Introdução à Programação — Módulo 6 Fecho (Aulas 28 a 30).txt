EXEMPLO RESOLVIDO
Acrescentar um recorde sem apagar os outros
Arcade.java
void guardarRecorde(String nome, int pontos) {
    try {
        Files.writeString(Path.of("recordes.txt"), nome + ";" + pontos + "\n",
                StandardOpenOption.CREATE, StandardOpenOption.APPEND);
    } catch (IOException e) {
        IO.println("Erro ao gravar: " + e.getMessage());
    }
}
CREATE cria o ficheiro; APPEND acrescenta no fim em vez de apagar.

JUNTAR TUDO
Mostrar o melhor recorde
Arcade.java
void mostrarMelhor(ArrayList<String> linhas) {
    String melhorNome = "";
    int melhor = -1;
    for (String l : linhas) {
        String[] p = l.split(";");
        int pts = Integer.parseInt(p[1]);
        if (pts > melhor) {
            melhor = pts;
            melhorNome = p[0];
        }
    }
    IO.println("? Recorde: " + melhorNome + " com " + melhor);
}

O mesmo programa, duas formas
compacto (Java 25)

tradicional
public class Ola {

=== PAGE 27 ===
AS PEÇAS
O que significa cada palavra?
Peça Por agora, basta saber que…
public class Ola { … } É a caixa que embrulha o programa: uma classe.
public Pode ser usado de qualquer sítio.
static Pertence à classe, não a um objeto (vais perceber em POO).
String[] args Um array com argumentos da linha de comandos.
System.out.println O «avô» do IO.println.

=== PAGE 28 ===
✍ ️  EXERCÍCIO
Converter um jogo para o formato tradicional
1 Envolve tudo em public class NomeDoFicheiro { }
2 Muda void main() para public static void main(String[] args)
3 Acrescenta static a todos os teus métodos
4 Acrescenta os import (ex.: import java.util.ArrayList;)
